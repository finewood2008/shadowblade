# 火花 · 一束火点燃创作者的全链路

> AI 内容营销桌面端 · 创作 → 分发 → 互动 → 变现 · macOS 即装即用

## 它解决什么

一个人做创作者，每天 80% 时间在搬运、改格式、抠平台规则。火花把这 80% 自动化：
- **一篇文案 → 13 个平台同步发**（抖音 / 小红书 / 快手 / 视频号 / B站 / TikTok / YouTube / IG / Threads / X / Pinterest / LinkedIn / Facebook）
- **AI 顺手生成**：文案扩写 / 图片 / 视频 / 标签
- **互动也托管**：评论 / 私信自动回复
- **任务市场接广告**：CPS / CPE / CPM 三种结算

## 30 秒安装

```bash
# Apple Silicon
curl -LO https://github.com/[your-user]/huohua/releases/download/v0.8.0/火花-0.8.0-arm64.dmg
xattr -cr 火花-0.8.0-arm64.dmg && open 火花-0.8.0-arm64.dmg

# Intel Mac
curl -LO https://github.com/[your-user]/huohua/releases/download/v0.8.0/火花-0.8.0-x64.dmg
```
