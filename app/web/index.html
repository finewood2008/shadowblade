Step 2 · Advanced (Optional)

引擎、API Key、智能补量、流水线开关。不改也能跑，默认配置即可生产。

引擎 · LLM / TTS / ASR + 音色 脚本用哪个 LLM、配音用谁、字幕怎么识别 ▾
LLM 凭据 · API Key / Base URL / Model 填了即覆盖 config.yml，按 LLM 提供方自动切换 ▾

填了即覆盖 config.yml → llm.{provider}.*， 按所选「LLM 提供方」自动切换。仅保存在你本地浏览器（localStorage），不会上传任何服务器。

智能补量 · Smart Pad 素材不足时从公开素材库自动下载补齐 ▾

素材不足时，从公开素材库按脚本关键词自动下载补足。 需要先在 config.yml 填 resource.{provider}.api_key

将以加密方式仅保存在你本地浏览器（localStorage），不会上传到任何服务器。
没填则回退使用 config.yml → resource.{provider}.api_key
